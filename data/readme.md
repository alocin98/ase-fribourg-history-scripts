# Data

This folder contains data we need to train our models.

## Test data

`testdata/pages/` holds 20 handwritten test pages (20 different writers, 5 different texts), and `testdata/pages.zip` contains the same images. Upload the zip as a document in the webapp to try the transcription.

The pages come from a handwriting dataset in which each scan starts with the printed text the writer copied. That printed block (between the two grey rules at the top) has been cropped away, so only the handwriting remains. The images were converted from TIFF to JPG (quality 90).
