MODE D’EMPLOI

Une différence, un choix.

  1. Choisis une page à gauche, puis Qwen ou CHURRO.
  2. Pour chaque passage surligné, regarde le manuscrit et clique sur le texte juste : référence (en haut) = le modèle reconnaît moins bien ; modèle (en bas) = le modèle reconnaît mieux que la référence.
  3. Si les deux sont faux, écris le bon texte dans le champ et enregistre.
  4. Clique Rapport pour voir le bilan par modèle, puis Exporter le CSV.

CSV : une ligne par différence, avec à chaque fois l’image source, le modèle, les deux textes, ton choix et le résultat (modele_pire, modele_mieux, les_deux_faux, non_traite).

Raccourcis : R = référence juste · M = modèle juste · ↑ / ↓ = différence · ← / → = transcription. Désactivés lorsque tu écris.
