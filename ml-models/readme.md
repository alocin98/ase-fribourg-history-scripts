# ML Models

Here, we are posting our ML experiments.

- `benchmark/`: the code that measures our models on the test split of
  `data/manuscripts` (transcription and language detection). See
  [benchmark/README.md](benchmark/README.md).
- `reports/`: the benchmark reports and the [leaderboard](reports/leaderboard.md).
- `models/`: one folder per model, with where to download it. Weights are not committed.
